# splitbill_em

## Obținerea APK-ului prin GitHub Actions
1. Creează un repository nou pe GitHub.
2. Încarcă **conținutul** folderului `splitbill_em` în rădăcina repository-ului.
3. Deschide fila **Actions**.
4. Selectează **Build splitbill_em APK** și apasă **Run workflow**.
5. După rulare, descarcă artefactul **splitbill_em-apk**.
6. În arhiva artefactului vei găsi `splitbill_em.apk`.

Workflow: `.github/workflows/build-apk.yml`.
